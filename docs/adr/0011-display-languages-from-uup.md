# Языки интерфейса — из выпуска Windows Update той же базовой сборки

Язык интерфейса добавляется в образ офлайн-обслуживанием (DISM): языковой пакет и возможности языка (базовые, рукописный ввод, OCR, речь). Пакеты берутся из выпуска Windows Update по CompDB, как и файлы редакций (ADR-0009):

- языковой пакет — `DesktopTargetCompDB_<язык>` → `Microsoft-Windows-Client-LanguagePack-Package~…~<язык>~.esd`; DISM не ставит ESD, поэтому wimlib разворачивает его в папку, и `AddPackage` получает папку;
- возможности языка — функции `Language.*~<язык>~` из `DesktopTargetCompDB_FOD_Neutral` со всеми зависимостями (шрифты, базовые), в порядке зависимостей; это полные `.cab`.

Пакеты должны совпадать с базовой сборкой образа (26100.1 для 24H2 и 25H2, 19041.1 для Windows 10 2004–22H2). Для образа из UUP они берутся из того же выпуска. Для своего ISO движок находит выпуск того же канала: 24H2 и 25H2 — `windows11`, его накопительное обновление у них общее, а пакет включения версии не берётся; Windows 10 — `windows10`. Базовую сборку пакетов движок проверяет по CompDB.

Языки ставятся **до** накопительного обновления, а обновление переводит и их. Поэтому если свой ISO уже обновлён (ревизия больше 1), вместе с языками по умолчанию встраивается последнее накопительное обновление. Без него часть текста новых языков осталась бы на языке образа, пока Windows не поставит следующее обновление (`latestUpdate: false` — так и будет, с предупреждением).

Язык Windows задаётся файлом ответов: `UILanguage` в International-Core-WinPE и в International-Core этапа oobeSystem. Язык установщика (`SetupUILanguage`), boot.wim и WinRE не меняются.

## Considered Options

- Официальный ISO языковых пакетов (Languages and Optional Features). Отклонено: несколько ГБ ради одного языка и ручное скачивание с сайта Microsoft; UUP даёт те же пакеты по одному.
- Ставить языки после установки (сценарием первого входа, через интернет). Отклонено: язык нужен уже на экранах первого запуска, а у установки может не быть сети.
- Не встраивать обновление повторно. Отклонено как поведение по умолчанию: перевод выходил бы неполным без видимой причины.

## Consequences

- Добавление языков к своему ISO требует интернета и прав администратора, даже если остальная сборка их не требует.
- Для обновлённого ISO добавление языка — это ещё около 5 ГБ скачивания и время встраивания обновления.
- Заодно своему ISO стало доступно и одно обновление (`latestUpdate: true`) — тем же путём.
- Список языков, которые можно добавить, — `languages --iso|--update` (метаданные выпуска, несколько МБ).
