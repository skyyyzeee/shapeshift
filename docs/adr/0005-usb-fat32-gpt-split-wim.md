# Флешка: FAT32 + GPT с разбиением WIM, без UEFI:NTFS

Отдельная загрузочная флешка размечается как GPT с одним разделом FAT32; `install.wim` больше 4 ГБ разбивается на `.swm`. Так флешка грузится на любом UEFI, включая Secure Boot, без стороннего загрузчика. Вариант Rufus (NTFS + UEFI:NTFS) отклонён из-за стороннего загрузчика и проблем с Secure Boot; Legacy BIOS (MBR) не поддерживается в первой версии.

## Considered Options

- NTFS + UEFI:NTFS — большие файлы и BIOS, но сторонний загрузчик и конфликты с Secure Boot.
- MBR + FAT32 — ради Legacy BIOS; можно добавить позже отдельной опцией.
