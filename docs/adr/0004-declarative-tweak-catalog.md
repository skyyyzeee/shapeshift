# Твики описываются декларативным каталогом, а не кодом

Каждый твик — запись в каталоге (JSON): идентификатор, локализованные название и описание, категория, применимые выпуски, конфликты, список действий с этапами. Интерфейс строится по каталогу, движок исполняет действия. Каталог подписан и обновляется отдельно от программы через GitHub.

## Consequences

- Добавить или починить твик — правка данных, без перекомпиляции и выпуска новой версии.
- Набор типов действий фиксирован в движке; твик, которому нужен новый тип действия, требует изменения кода.
- Разметка встроенных приложений (понятное имя, безопасно ли удалять) тоже живёт в каталоге, а сам список приложений читается из образа.
