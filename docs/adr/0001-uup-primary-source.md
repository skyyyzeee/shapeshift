# UUP — основной источник образа

Официальная страница загрузки Microsoft (механизм Fido/Rufus) недоступна с российских IP, а серверы Windows Update — доступны. Поэтому основной источник — UUP, причём напрямую через Windows Update, без зависимости от uupdump.net. Официальная страница остаётся запасным источником, свой ISO — всегда доступным.

## Consequences

- UUP же служит единственным источником языковых пакетов и компонентов по требованию под конкретный выпуск — пользователю не нужно искать их самому.
- Движку нужно уметь собирать образ из файлов UUP (ESD → WIM, конвертация редакций), это крупный отдельный модуль.
- LTSC через UUP не получить: LTSC доступен только как свой ISO.
