# ISO собирается через IMAPI2, wimlib подключается отдельной DLL

ISO собирается встроенным в Windows IMAPI2 (UDF, двойная загрузка BIOS + UEFI), а не `oscdimg`: `oscdimg` входит в ADK и его нельзя просто распространять с программой; он остаётся запасным вариантом, если ADK установлен. wimlib (быстрый экспорт и сжатие WIM, ESD → WIM, разбиение на `.swm`) распространяется под LGPLv3/GPLv3, поэтому подключается только как отдельная динамически загружаемая DLL — это позволяет держать основной код под MIT.

## Consequences

- wimlib нельзя статически линковать или встраивать в сборку .NET; DLL поставляется рядом с программой вместе с её лицензией.
