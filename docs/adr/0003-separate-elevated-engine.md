# Движок — отдельный повышенный процесс, интерфейс без прав администратора

Офлайн-обслуживание требует прав администратора, но окно, запущенное от администратора, не принимает перетаскивание файлов из Проводника (UIPI). Поэтому интерфейс работает как обычный процесс, а движок — отдельная консольная программа, запускаемая с повышением при старте сборки (один запрос UAC). Связь — через именованный канал.

## Consequences

- Движок полностью работоспособен без интерфейса: сборка по профилю из командной строки, скрипты, автотесты.
- Всё взаимодействие интерфейса с движком идёт через протокол канала (прогресс, лог, отмена, результат) — никакой общей памяти и прямых вызовов.
