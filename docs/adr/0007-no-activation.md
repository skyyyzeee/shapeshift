# Никаких средств активации и встроенных ключей

Shapeshift не встраивает ни средств активации (MAS, KMS-эмуляторы и т. п.), ни каких-либо ключей продукта. Редакция для установки выбирается её номером в образе (`InstallFrom` → `/IMAGE/INDEX`) с нулевым ключом, поэтому установщик не спрашивает ключ, а Windows ставится неактивированной — так же, как при нажатии «У меня нет ключа продукта». Пользователь может вписать свой ключ. Средства активации — юридический риск для открытого проекта, гарантированные срабатывания антивирусов и риск блокировки репозитория на GitHub.

## Considered Options

- Общедоступные ключи установки (generic keys) для выбора редакции — первоначальный план. Отклонено: выбор по номеру в образе делает то же самое без хранения списка ключей в программе и его поддержки для каждой редакции.

## Consequences

- Чтобы выбрать редакцию, нужен образ (номер редакции берётся из него): `answerfile` без `--iso` редакцию не задаёт.
