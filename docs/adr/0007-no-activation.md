# Никаких средств активации

Shapeshift ставит в файл ответов только общедоступные ключи установки (выбор редакции без ввода ключа) и поле для собственного ключа пользователя. Средства активации (MAS, KMS-эмуляторы и т. п.) не встраиваются и не скачиваются: это юридический риск для открытого проекта, а также гарантированные срабатывания антивирусов и риск блокировки репозитория на GitHub.
