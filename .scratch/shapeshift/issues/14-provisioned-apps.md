# 14: Встроенные приложения

**What to build:** На шаге «Настройка» пользователь видит список встроенных приложений, прочитанный из самого образа. У известных каталогу — понятное название и пометка «безопасно / может сломать», у неизвестных — техническое имя и пометка «неизвестно». Кнопка «рекомендованные» выбирает рекомендованные к удалению. Выбранные приложения удаляются из образа офлайн. Список приложений читается из образа, разметка — из каталога (ADR-0004). Сценарии спецификации: 36–39.

**Blocked by:** 10, 13

**Дополнительно из 13:** монтирование образа через DISM API (управляемая обёртка `Microsoft.Dism`) с прогрессом в канале; автоочистка зависших монтирований при старте движка и команда `cleanup`; отмена во время монтирования — монтирование отключается без сохранения, исходный образ не тронут; проверка версии DISM хоста относительно выпуска (предупреждение и путь к DISM из ADK). Тесты с монтированием требуют прав администратора — отдельная категория.

**Status:** ready-for-agent
