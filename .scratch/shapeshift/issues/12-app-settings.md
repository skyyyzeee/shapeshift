# 12: Настройки программы

**What to build:** На странице настроек пользователь переключает язык интерфейса (RU/EN), выбирает рабочую папку (по умолчанию — на диске с наибольшим свободным местом) и видит размер кэша с кнопкой очистки. Описания твиков из каталога тоже отображаются на выбранном языке. Сценарии спецификации: 68–72.

## Comments

**Сделано (2026-10-20).** «Параметры» — шестерёнка внизу боковой панели (не шаг мастера: кнопок «Назад/Далее» на ней нет).

- **Язык**: «Как в Windows» / Русский / English; применяется при запуске (`PrimaryLanguageOverride` + культура интерфейса) — после выбора окно предлагает перезапуститься. Подписи «Вкл./Выкл.» переключателей заданы из ресурсов программы: стандартные WinUI берёт из языка Windows.
- **Рабочая папка**: по умолчанию — на диске с наибольшим свободным местом (`%LOCALAPPDATA%\Shapeshift\Workspace` на системном диске, иначе `X:\Shapeshift\Workspace` — путь короткий из-за предела MAX_PATH у IMAPI); «Изменить…» / «По умолчанию». Окно передаёт её движку и для сводки (`--dry-run`), и для сборки — место проверяется на нужном диске.
- **Кэш**: размер всего содержимого рабочей папки (после удачной сборки она пуста — остальное кэш и остатки прерванных сборок) и «Очистить» с подтверждением; во время сборки — недоступно.
- **Хранение**: `%LOCALAPPDATA%\Shapeshift\settings.json`; испорченный файл не мешает запуску.
- Аргументы запуска движка с повышением: путь, оканчивающийся на `\` (корень диска), больше не ломает кавычки.

Проверено через UI Automation: страница открывается; выбор English → плашка о перезапуске → после перезапуска окно на английском. Выбор папки диалогом не проверен автоматически.
