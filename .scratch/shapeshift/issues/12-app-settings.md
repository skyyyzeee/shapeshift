# 12: Настройки программы

**What to build:** На странице настроек пользователь переключает язык интерфейса (RU/EN), выбирает рабочую папку (по умолчанию — на диске с наибольшим свободным местом) и видит размер кэша с кнопкой очистки. Описания твиков из каталога тоже отображаются на выбранном языке. Сценарии спецификации: 68–72.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Переключение языка интерфейса RU/EN; применяется с перезапуском окна или сразу
- [ ] Рабочая папка по умолчанию — на диске с наибольшим свободным местом; можно выбрать другую
- [ ] Выбранная рабочая папка передаётся движку при сборке
- [ ] Размер кэша и кнопка очистки (с подтверждением)
- [ ] Настройки сохраняются между запусками
