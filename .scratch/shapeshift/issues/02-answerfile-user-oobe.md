# 02: Пользователь и OOBE в файле ответов

**What to build:** Пользователь задаёт в профиле локального пользователя и параметры установки, и `answerfile` выдаёт файл ответов, с которым установка проходит без участия: создаётся локальная учётная запись, аккаунт Microsoft и интернет не требуются, экраны OOBE пропускаются, компьютер получает заданное имя. Пароль по умолчанию требуется сменить при первом входе; режим «хранить пароль» включается явно. Авторазметка диска (стирает диск 0) поддерживается, но по умолчанию выключена — она нужна стенду Hyper-V (05). Сценарии спецификации: 25–33.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Локальный пользователь с заданным именем создаётся; входит в группу администраторов
- [ ] Режим пароля по умолчанию — смена при первом входе; реальный пароль в файл ответов не попадает
- [ ] Режим «хранить пароль» кладёт пароль в файл ответов; движок пишет предупреждение в лог
- [ ] Автовход, обход аккаунта Microsoft / интернета, пропуск экранов OOBE и вопросов о приватности, имя компьютера — каждый управляется профилем
- [ ] Авторазметка диска (GPT: EFI, MSR, Windows, WinRE) включается только явным флагом профиля; по умолчанию выключена
- [ ] Снимки и проверка по схеме для профилей с разными комбинациями опций
