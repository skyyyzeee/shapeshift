# 24: Языки интерфейса

**What to build:** На шаге «Редакции и языки» пользователь добавляет один или несколько языков интерфейса и выбирает язык по умолчанию. Движок скачивает через UUP языковые пакеты и компоненты по требованию (рукописный ввод, OCR, речь) точно под выпуск образа и устанавливает их при офлайн-обслуживании. Язык установщика и WinRE не меняется (вне рамок). Регион по-прежнему задаётся отдельно (03). Сценарии спецификации: 16–18.

**Blocked by:** 03, 13, 19

## Заметки

- Для своего ISO пакеты берутся из выпуска канала той же базовой сборки; уже обновлённый образ получает обновление заново (ADR-0011).
- `UILanguage` этапа WinPE остаётся языком образа: с добавленным языком Setup отбрасывает языковые настройки и спрашивает язык (проверено на стенде).
- Без интернета движок берёт выпуск из кэша (`build --download-only` заранее).
- Образ с обновлением большой (install.wim одной редакции ~9,7 ГБ): нужна очистка компонентов после обновления — задача 32.
