# 24: Языки интерфейса

**What to build:** На шаге «Редакции и языки» пользователь добавляет один или несколько языков интерфейса и выбирает язык по умолчанию. Движок скачивает через UUP языковые пакеты и компоненты по требованию (рукописный ввод, OCR, речь) точно под выпуск образа и устанавливает их при офлайн-обслуживании. Язык установщика и WinRE не меняется (вне рамок). Регион по-прежнему задаётся отдельно (03). Сценарии спецификации: 16–18.

**Blocked by:** 03, 13, 19

**Status:** ready-for-agent

- [ ] Список доступных языков для выпуска образа (и для своего ISO, и для UUP)
- [ ] Языковые пакеты и компоненты по требованию скачиваются через UUP под точный выпуск, хранятся в кэше
- [ ] Установка при офлайн-обслуживании; выбранный язык по умолчанию становится языком системы
- [ ] Выпуск, для которого языковые пакеты недоступны, — понятная ошибка до начала монтирования
- [ ] Тест «с офлайн-обслуживанием»: языки в образе, язык по умолчанию
- [ ] Стенд Hyper-V: система загружается на выбранном языке интерфейса
