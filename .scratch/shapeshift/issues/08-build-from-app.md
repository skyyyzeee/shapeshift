# 08: Сборка из окна

**What to build:** Пользователь нажимает «Собрать» на шаге «Результат», видит сводку «что будет сделано», подтверждает — и после одного запроса UAC следит за прогрессом по этапам с подробным логом. Сборку можно отменить в любой момент; лог можно сохранить в файл. Окно запускает движок с повышением и общается с ним по именованному каналу сообщениями JSON (начало/конец этапа, прогресс, строка лога, предупреждение, ошибка, результат; от окна — отмена). ## Comments

**Сделано (2026-10-20).**

- **Движок**: `build --pipe <имя>` — сообщения JSON по строке (`step`, `progress`, `log`, `warning`, `error`, `done`, `cancelled`, последним `exit` с кодом); окно — сервер канала. Отмена — командой `cancel` или обрывом канала (окно закрыли), на любом шаге, включая чтение профиля. Код выхода 4 — отменено. `build --dry-run --json` — сводка для окна (`--json` без `--dry-run` отклоняется). Протокол покрыт тестами через шов CLI: тест — «окно».
- **Окно**: шаг «Результат» — путь сохранения (по умолчанию «Документы\<образ>-shapeshift.iso», «Изменить…»), сводка из пробного прогона без повышения, предупреждения и ошибки (например, нет места) до запуска; «Собрать» → движок через `runas` (один запрос UAC) → шаг, общий прогресс, журнал, «Отменить»; итог: «Показать в папке», «Сохранить журнал…», «К сводке». Пока идёт сборка, уйти с шага нельзя.

Проверено: протокол — тестами; сводка в окне — запуском и снимком (Windows 11 24H2: распаковка 8,0 ГБ, упаковка 8,0 ГБ, нужно 16,4 ГБ на C:). **Не проверено**: сборка из окна целиком — запуск с повышением требует подтверждения UAC человеком.
