# 08: Сборка из окна

**What to build:** Пользователь нажимает «Собрать» на шаге «Результат», видит сводку «что будет сделано», подтверждает — и после одного запроса UAC следит за прогрессом по этапам с подробным логом. Сборку можно отменить в любой момент; лог можно сохранить в файл. Окно запускает движок с повышением и общается с ним по именованному каналу сообщениями JSON (начало/конец этапа, прогресс, строка лога, предупреждение, ошибка, результат; от окна — отмена). Сценарии спецификации: 55, 57–59, 61.
