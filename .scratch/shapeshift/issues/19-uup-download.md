# 19: Скачивание UUP

**What to build:** Пользователь выбрал выпуск, язык и редакции — движок скачивает нужные файлы UUP с прогрессом, скоростью и оставшимся временем. Прерванное скачивание продолжается с места остановки, файлы проверяются по хешам и сохраняются в кэше для следующих сборок. Сценарии спецификации: 10–12, 72.

## Заметки

- Команды: `uup files --update <id> --lang ru-RU --edition Professional [--edition Core] [--list] [--json]` — сколько скачать и сколько уже в кэше; `uup download … [--pipe]` — скачивание. Первым скачивается `AggregatedMetadata.cab`, по его CompDB выбираются файлы (ADR-0009).
- Ссылки — `GetExtendedUpdateInfo2` на `fe3cr…/client.asmx/secured` (в заголовке адресата — `fe3…/secured`, иначе ответ пустой); одни на всё скачивание, заново — только если истекли.
- Кэш: `cache\uup\files\<SHA-1>`, `.part` для недокачанного; 4 файла параллельно, до 5 попыток с докачкой при обрыве, повреждённый файл — заново один раз; место проверяется до начала.
- Канал: шаги `DownloadMetadata`, `DownloadFiles`, сообщение `transfer` (`bytes`, `total`, `bytesPerSecond`, `secondsLeft`).
- Окно: «Источник» → «Скачать» — объём для выбранного, «Скачать» / «Отменить», полоса, скорость, оставшееся время; движок без повышения.
- Повторное использование кэша проверено повторным скачиванием (ничего не качается); «повторная сборка» — когда появится сборка из UUP (задача 20). Размер кэша — часть рабочей папки, его уже считает «Параметры».
- Живая проверка: Windows 11 25H2, ru-RU, Pro — 405 файлов, 9,15 ГБ, ~7,6 МБ/с.
