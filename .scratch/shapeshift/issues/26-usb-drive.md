# 26: Отдельная загрузочная флешка

**What to build:** На шаге «Результат» пользователь выбирает «Флешка», указывает накопитель, подтверждает форматирование (с названием и размером накопителя) и получает флешку, которая грузится на любом UEFI, включая Secure Boot. Флешка размечается как GPT с одним разделом FAT32; `install.wim` больше 4 ГБ разбивается на `.swm` (ADR-0005). Сценарии спецификации: 53, 54.

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] Список съёмных накопителей; системные и несъёмные диски не предлагаются
- [ ] Обязательное подтверждение с названием, размером и предупреждением о стирании
- [ ] Разметка GPT, один раздел FAT32, копирование файлов образа
- [ ] `install.wim` больше 4 ГБ разбивается на `.swm` через wimlib; установщик принимает разбитый образ
- [ ] Выбор результата хранится в профиле; CLI требует явного флага подтверждения для форматирования
- [ ] Проверка: флешка загружается в ВМ Hyper-V поколения 2 с Secure Boot (через проброс диска) или вручную на реальном ПК
