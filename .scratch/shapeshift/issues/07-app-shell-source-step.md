# 07: Окно и шаг «Источник»

**What to build:** Пользователь открывает Shapeshift и видит минималистичное окно WinUI 3 (Mica, системная тема) с мастером из пяти шагов: Источник → Редакции и языки → Установка → Настройка → Результат. На шаге «Источник» он выбирает свой ISO диалогом или перетаскивает его из Проводника, и окно показывает выпуск, архитектуру и редакции — сведения получает движок, запущенный без повышения. Неподходящий образ — понятное сообщение. Остальные шаги пока заглушки. Окно работает без прав администратора (ADR-0003). Строки — в ресурсах с первого дня, RU и EN по языку системы. Сценарии спецификации: 1–4, 59, 68, 78.
