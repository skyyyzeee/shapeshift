# 07: Окно и шаг «Источник»

**What to build:** Пользователь открывает Shapeshift и видит минималистичное окно WinUI 3 (Mica, системная тема) с мастером из пяти шагов: Источник → Редакции и языки → Установка → Настройка → Результат. На шаге «Источник» он выбирает свой ISO диалогом или перетаскивает его из Проводника, и окно показывает выпуск, архитектуру и редакции — сведения получает движок, запущенный без повышения. Неподходящий образ — понятное сообщение. Остальные шаги пока заглушки. Окно работает без прав администратора (ADR-0003). Строки — в ресурсах с первого дня, RU и EN по языку системы. Сценарии спецификации: 1–4, 59, 68, 78.

## Comments

**Сделано (2026-10-20).** Проект `src/Shapeshift.App` (WinUI 3, Windows App SDK 2.5.1, без MSIX, Windows App SDK внутри), исполняемый файл `Shapeshift.exe`; движок, каталог и ресурсы лежат рядом.

- **Окно**: Mica, тема по системе, своя строка заголовка; мастер на `NavigationView` (5 шагов слева, шаги после «Источника» выключены, пока нет подходящего образа), «Назад»/«Далее» внизу, «Продвинутый режим» в нижней части панели (пока без эффекта).
- **«Источник»**: зона перетаскивания и «Выбрать файл…» (новый `FileOpenPicker` Windows App SDK — работает без упаковки); после выбора — карточка образа (имя, выпуск · архитектура · язык, редакции) и «Другой файл…»; ошибки — `InfoBar` с локализованным текстом.
- **`inspect --json`** — контракт движок ↔ окно (снимок в тестах); у каждой причины отказа есть код (`server`, `arm64`, `too-old`…), окно показывает свой текст по коду. Движок пишет вывод в UTF-8: перенаправленная консоль на русской Windows иначе отдаёт cp866.
- **`Shapeshift.exe образ.iso`** открывает образ сразу (заодно «Открыть с помощью»).
- **Строки** — `Strings/{ru-RU,en-US}/Resources.resw`, язык — по Windows.

Проверено вручную (запуск, снимок окна, нажатие кнопок через UI Automation): Windows 11 24H2 → карточка с 6 редакциями и активной «Далее»; «Далее» → шаг 2; Windows Server 2025 → ошибка, шаги выключены. **Не проверено автоматически**: перетаскивание и диалог выбора файла — их нельзя нажать скриптом без вмешательства в рабочий стол; проверь руками.
