# 13: Офлайн-обслуживание: монтирование и редакции

**What to build:** Первая сборка с офлайн-обслуживанием. На шаге «Редакции и языки» (и в профиле для CLI) пользователь выбирает, какие редакции оставить, и получает образ только с ними. Движок монтирует образ через управляемую обёртку DISM API, удаляет лишние редакции и пересжимает WIM (wimlib, отдельная DLL — ADR-0006). При старте движок автоматически отключает зависшие монтирования без сохранения; то же делает команда `cleanup`. Отмена не портит исходный образ. Если DISM хоста старше выпуска образа — предупреждение и предложение использовать DISM из ADK. Сценарии спецификации: 14, 58, 73, 74.
