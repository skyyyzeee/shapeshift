# 28: Portable zip и выпуск

**What to build:** Пользователь скачивает zip, распаковывает и запускает Shapeshift без установки .NET и Windows App SDK. Сборка выпуска собирает окно и движок как self-contained приложение (без MSIX), кладёт рядом DLL wimlib с её лицензией и лицензию MIT. Сценарий спецификации: 77.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Self-contained сборка окна и движка; запуск на чистой Windows 10 22H2 / 11 без предустановленных рантаймов
- [ ] DLL wimlib и текст её лицензии в архиве; лицензия MIT для основного кода
- [ ] Движок запускается из той же папки, что и окно (повышение для сборки работает)
- [ ] Автоматическая сборка выпуска (zip с номером версии)
- [ ] Программа не пишет ничего рядом с собой, кроме явно выбранных пользователем путей (настройки — в профиле пользователя)
