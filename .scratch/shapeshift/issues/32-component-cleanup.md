# 32: Очистка компонентов после встраивания обновления

**What to build:** После встраивания накопительного обновления (UUP или свой ISO) образ заметно растёт: старые версии компонентов остаются в WinSxS. На стенде install.wim одной редакции Pro после языка и обновления — 9,7 ГБ (официальный ISO со всеми редакциями — около 5–6 ГБ); шаг `CompactImage` (пересборка WIM wimlib) убирает лишь ~3 %. Нужна очистка хранилища компонентов в смонтированном образе (как `DISM /Cleanup-Image /StartComponentCleanup /ResetBase`) после обновления, до сжатия.
