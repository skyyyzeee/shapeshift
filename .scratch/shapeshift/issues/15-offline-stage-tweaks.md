# 15: Твики этапа «в образе»

**What to build:** Твики, которым нужен этап «в образе», применяются к офлайн-реестру смонтированного образа: отключение автошифрования BitLocker, зарезервированного хранилища, гибернации, поведение обновлений и другие, что надёжнее задавать до установки. Каталог описывает их так же, как остальные твики; пользователь не видит разницы между механизмами (ADR-0002). Если в профиле нет твиков этого этапа — офлайн-обслуживание ради них не запускается. Сценарии спецификации: 42, 43.

**Blocked by:** 06, 13

**Status:** ready-for-agent

- [ ] Тип действия «значение реестра» с этапом «в образе»: кусты SYSTEM, SOFTWARE, DEFAULT (профиль пользователя по умолчанию)
- [ ] Твики категории «Система» в каталоге: автошифрование BitLocker, зарезервированное хранилище, гибернация, поведение обновлений
- [ ] Планировщик включает офлайн-обслуживание, только если оно действительно нужно; `--dry-run` это показывает
- [ ] Тест «с офлайн-обслуживанием»: значения офлайн-реестра в результате
- [ ] Стенд Hyper-V: автошифрование BitLocker не включилось, значения реестра на месте
