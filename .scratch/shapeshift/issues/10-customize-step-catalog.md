# 10: Шаг «Настройка» по каталогу

**What to build:** На шаге «Настройка» пользователь видит твики из каталога, сгруппированные по категориям, с описанием каждого. Твики, неприменимые к выбранному выпуску, скрыты или помечены; включить конфликтующие одновременно нельзя. По умолчанию видны основные твики, продвинутый режим раскрывает остальные. Экран строится из каталога целиком — новый твик в каталоге появляется в окне без изменения кода. Сценарии спецификации: 40–43, 46–49.

**Blocked by:** 06, 07

**Status:** done

- [x] Включение твика, конфликтующего с уже включённым, предлагает выключить другой

## Comments

**Сделано (2026-10-20).** Шаг «Настройка» строится из каталога, который отдаёт движок: `catalog list --json [--iso]` — категории и твики с текстами на всех языках каталога, фильтром выпусков и применимостью к образу (контракт закреплён снимком). Окно не знает твиков заранее — новый твик в каталоге появляется без пересборки окна.

- Категория на карточку, твик — строка с описанием и переключателем; неприменимый к образу — выключен, с подписью «Не подходит к этому образу: только для Windows 11, сборка 26100 или новее».
- Конфликт: включение твика, конфликтующего с включённым, открывает диалог «выключить те и включить этот / оставить как было».
- `advanced` в каталоге: такие твики видны только в продвинутом режиме и в профиль идут только в нём.
- Категория «Обход ограничений» — на шаге «Установка», здесь не показывается.
- Выбор сохраняется при смене образа (для применимых твиков); в профиль идут твики «Установки» + «Настройки»; на «Результате» — строка «Твики (N): …».

Проверено через UI Automation на Windows 11 24H2: 12 твиков в обычном режиме, 13 — в продвинутом; два включённых твика попали в сводку, движок принял профиль. Неприменимые твики в окне не проверены вживую (нет образа Windows 10) — применимость проверена тестом движка.
