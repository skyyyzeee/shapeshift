# 20: Сборка образа из UUP

**What to build:** Пользователь выбирает на шаге «Источник» скачивание через UUP, проходит мастер и получает готовый результат — так же, как со своим ISO. Движок собирает из скачанных файлов UUP установочный образ (ESD → WIM через wimlib, `boot.wim`, файлы установщика) с базовыми редакциями, после чего сборка продолжается обычным путём. Сценарии спецификации: 5, 6.
