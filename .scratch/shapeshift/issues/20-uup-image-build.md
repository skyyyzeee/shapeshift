# 20: Сборка образа из UUP

**What to build:** Пользователь выбирает на шаге «Источник» скачивание через UUP, проходит мастер и получает готовый результат — так же, как со своим ISO. Движок собирает из скачанных файлов UUP установочный образ (ESD → WIM через wimlib, `boot.wim`, файлы установщика) с базовыми редакциями, после чего сборка продолжается обычным путём. ## Заметки

- Носитель собирается только wimlib (ADR-0010): образ 1 образа редакции — файлы установщика, образ 3 — `install.wim` по ссылкам на пакеты (CAB перепаковываются во временные WIM), образ 2 — `Winre.wim` и `boot.wim` (PE + установщик, загрузочный образ 2). Без DISM и прав администратора.
- Профиль: `source.uup` — `channel`, `language`, необязательный `updateId` (без него — самый новый выпуск канала на момент сборки); редакции — поле `editions` (по умолчанию Pro).
- План: шаги `DownloadFiles` (только образы редакций и пакеты, ~2,9 ГБ для Pro ru-RU) и `AssembleImage`; версия образа — из CompDB (исходная сборка, например 26100.1).
- Окно: «Источник → Скачать» — выбранное становится источником мастера; на шаге «Результат» прогресс скачивания со скоростью и временем. `uup files/download --media-only` — то же, что качает сборка.
- Живая проверка: Windows 11 25H2 ru-RU Pro из настоящего UUP — сборка движком ~3 мин из кэша, ISO 4,4 ГБ; стенд Hyper-V — установка без участия, все проверки сценария.
- Стенд: без анимации первого входа рабочий стол появляется раньше, чем выполнятся команды первого входа, — стенд теперь ждёт, пока в сеансе не останется cmd/PowerShell.
- Не равен официальному ISO: нет встроенных приложений (задача 30) и последнего обновления (задача 22).
