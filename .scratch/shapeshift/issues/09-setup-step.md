# 09: Шаг «Установка»

**What to build:** На шаге «Установка» пользователь настраивает всё, что делает установку автоматической: обход ограничений, локального пользователя и режим пароля (с предупреждением при хранении), автовход, пропуск OOBE, обход аккаунта Microsoft, имя компьютера, регион (форматы, раскладки, часовой пояс), свой ключ продукта. Авторазметка диска видна только в продвинутом режиме и требует подтверждения с предупреждением о стирании. Выборы попадают в профиль и в сборку. Сценарии спецификации: 19, 20, 24–35, 49.

## Comments

**Сделано (2026-10-20).** Шаг «Установка»: требования Windows 11 (один переключатель; в продвинутом режиме — четыре проверки отдельно; только для образа Windows 11), локальный пользователь (имя, пароль «при первом входе» по умолчанию или «сохранить в образе» с предупреждением, автовход только при сохранённом пароле), первый запуск (пропуск экранов, без аккаунта Microsoft, имя компьютера), регион (форматы, раскладки — первая основная, добавление поиском, часовой пояс), ключ продукта; стирание диска 0 — только в продвинутом режиме и через диалог подтверждения.

- Проверки полей — те же `NameRules`, что в движке; ошибка — подсказкой у поля, «Далее» и следующие шаги недоступны.
- Значения по умолчанию: обход требований включён, пользователь создаётся, без экранов OOBE и аккаунта Microsoft, регион и часовой пояс — как у этого компьютера, раскладки — свои + английская.
- Окно собирает профиль из выборов (`ProfileDraft` → тот же JSON, что принимает CLI); на шаге «Результат» добавлен блок «Установка» — что попадёт в образ.
- Выбор редакции для установки (`setup.edition`) — на шаге «Редакции и языки» (задача 13).

Проверено через UI Automation: пустое имя → «Далее» недоступна; «Алексей» → доступна; `bad%name` → подсказка и недоступна; на «Результате» движок принял профиль окна, сводка показывает выборы.
