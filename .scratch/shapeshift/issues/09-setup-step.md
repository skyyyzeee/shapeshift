# 09: Шаг «Установка»

**What to build:** На шаге «Установка» пользователь настраивает всё, что делает установку автоматической: обход ограничений, локального пользователя и режим пароля (с предупреждением при хранении), автовход, пропуск OOBE, обход аккаунта Microsoft, имя компьютера, регион (форматы, раскладки, часовой пояс), свой ключ продукта. Авторазметка диска видна только в продвинутом режиме и требует подтверждения с предупреждением о стирании. Выборы попадают в профиль и в сборку. Сценарии спецификации: 19, 20, 24–35, 49.

**Blocked by:** 02, 03, 07

**Status:** ready-for-agent

- [ ] Все параметры установки из 02 и 03 доступны на шаге и попадают в профиль сборки
- [ ] Режим пароля по умолчанию — смена при первом входе; при выборе «хранить» показывается предупреждение
- [ ] Регион выбирается независимо от языка интерфейса; список раскладок с раскладкой по умолчанию
- [ ] Авторазметка диска видна только в продвинутом режиме и включается через диалог подтверждения
- [ ] Неверное имя пользователя или компьютера — подсказка у поля, «Далее» недоступно
- [ ] Сборка из окна с этими настройками даёт тот же файл ответов, что `answerfile` с эквивалентным профилем
