# 22: Накопительное обновление

**What to build:** Пользователь включает «встроить последнее накопительное обновление», и установленная система актуальна сразу. Обновление скачивается через UUP для выпуска образа и встраивается при офлайн-обслуживании. Для источника UUP опция включена по умолчанию, для своего ISO — выключена. Сценарии спецификации: 22, 23.

**Blocked by:** 13, 20

**Status:** ready-for-agent

- [ ] Поиск и скачивание последнего накопительного обновления для выпуска образа (в том числе своего ISO)
- [ ] Встраивание в образ при офлайн-обслуживании, с прогрессом
- [ ] Умолчание: включено для UUP, выключено для своего ISO; хранится в профиле
- [ ] Обновление уже встроено или неприменимо — пропуск с записью в лог
- [ ] Тест «с офлайн-обслуживанием»: номер сборки образа вырос до номера обновления
