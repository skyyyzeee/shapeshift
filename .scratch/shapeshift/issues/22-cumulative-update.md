**What to build:** Пользователь включает «встроить последнее накопительное обновление», и установленная система актуальна сразу. ## Заметки

- Для выпусков UUP: обновления — из самого выпуска, по CompDB (`outer.AggregatedMetadata_KB…` — накопительные, `EKBUpdateCompDB_KB…` — пакет включения версии, `-NDP…` — .NET; SafeOS и SetupDU не встраиваются в Windows). Встраивается последнее накопительное — DISM сам ставит контрольные точки (`.msu` из той же папки, жёсткие ссылки на файлы кэша с настоящими именами).
- `latestUpdate` в профиле: для UUP по умолчанию да; для своего ISO — ошибка «пока не поддерживается» (первый пункт — поиск обновления для чужой сборки — остаётся открытым; канал «24H2 исходная» тоже без обновлений).
- Обновлений в выпуске нет — предупреждение, образ остаётся исходной сборкой.
- Живая проверка (DISM в ВМ стенда, `tools/bench/Invoke-BuildInVm.ps1`): Windows 11 25H2 ru-RU Pro — ISO 7,8 ГБ, образ 26200.9457; стенд — установленная система 26200.9457, все проверки. В ВМ (2 ядра, 4 ГБ) сборка ~2 ч; журнал DISM полон «Hydration failed» и «MsuManager … 0x80070032» — это шум, установка продолжается.
- ISO больше 4 ГБ: для флешки FAT32 нужен разрез WIM (задача 26).
