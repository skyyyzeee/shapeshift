# 29: Предустановка своих программ

**What to build:** На шаге «Настройка» (отдельная карточка «Программы») пользователь добавляет программы, которые поставятся сами при установке Windows. Два способа:

1. **Из winget (онлайн).** Выбор из короткого списка популярных (Telegram, 7-Zip, Chrome/Firefox, VLC, Notepad++…) или ввод ID пакета winget. Устанавливается при первом входе, если есть интернет; без интернета — пропускается с записью в журнал, установка Windows не ломается.
2. **Свой установщик (офлайн).** Файл `.exe`/`.msi` (или папка, например Office Deployment Tool с `configuration.xml`, 1С) и параметры тихой установки. Файлы кладутся в образ через `sources\$OEM$` — DISM и права администратора не нужны. Для `.msi` параметры по умолчанию — `/qn /norestart`; для известных установщиков (Inno Setup, NSIS) — подсказка параметров.

Установка — один сценарий, который движок кладёт в образ и запускает файл ответов: по порядку, с журналом в `C:\Windows\Setup\Shapeshift\programs.log`, с таймаутом на каждую программу; сбой одной не останавливает остальные. Выбор хранится в профиле (`programs`), пути к установщикам — относительные к профилю или абсолютные.

## Вопросы к решению

- Office: ODT скачивает Office сам (нужен интернет) или из заранее скачанной папки — поддержать оба через `setup.exe /configure configuration.xml`.
- 1С: дистрибутив большой и с лицензией — только как «свой установщик», без каталога.
- Подписи и происхождение установщиков — ответственность пользователя; Shapeshift ничего не скачивает при сборке (кроме будущего UUP).
