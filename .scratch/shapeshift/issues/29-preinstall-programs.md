# 29: Предустановка своих программ

**What to build:** На шаге «Настройка» (отдельная карточка «Программы») пользователь добавляет программы, которые поставятся сами при установке Windows. Два способа:

1. **Из winget (онлайн).** Выбор из короткого списка популярных (Telegram, 7-Zip, Chrome/Firefox, VLC, Notepad++…) или ввод ID пакета winget. Устанавливается при первом входе, если есть интернет; без интернета — пропускается с записью в журнал, установка Windows не ломается.
2. **Свой установщик (офлайн).** Файл `.exe`/`.msi`/`.cmd`/`.bat`/`.ps1` или папка (Office Deployment Tool с `configuration.xml`, 1С) и параметры тихой установки. Файлы кладутся в образ через `sources\$OEM$` — DISM и права администратора не нужны.

Установка — один сценарий, который движок кладёт в образ и запускает файл ответов (ADR-0008).

## Заметки

- Предупреждения: `answerfile` без сборки не несёт установщиков; `removeApps` с `Microsoft.DesktopAppInstaller` делает пакеты winget невозможными.
- Скачивание пакетов winget при сборке (офлайн-установка) — отложено (ADR-0008).
- Окно проверено вживую (UI Automation + снимок): карточка, флажки популярных, добавленные из профиля, выбор файла в папке. Диалоги выбора файла/папки вживую не нажимались.
