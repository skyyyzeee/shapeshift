# 25: Флешка Ventoy

**What to build:** На шаге «Результат» пользователь выбирает «Флешка Ventoy»: программа сама находит подключённые флешки Ventoy и кладёт результат на выбранную как файл ISO. Сначала прототипом подтверждается, что файл ответов внутри ISO срабатывает при загрузке через Ventoy; если нет — задача фиксирует найденное решение. Сценарии спецификации: 51, 52.
