# 11: Профили, пресеты и экспорт файла ответов

**What to build:** Пользователь сохраняет все выборы мастера в профиль и загружает его позже — в том числе для другого выпуска, получая отчёт о неприменимых твиках. Можно начать с пресета («Чистая установка», «Минимальная», «Приватность») и экспортировать только файл ответов, чтобы использовать его с обычным ISO. Профиль — тот же файл, что принимает CLI, поэтому им можно поделиться. Сценарии спецификации: 62–67.

**Blocked by:** 09, 10

**Status:** ready-for-agent

- [ ] Сохранение и загрузка профиля из окна; формат совпадает с форматом CLI
- [ ] Загрузка профиля для другого выпуска: отчёт о неприменимых твиках и о том, что изменится
- [ ] Профиль старой версии формата загружается (или понятная ошибка о несовместимости)
- [ ] Три встроенных пресета, выбираемых при старте мастера
- [ ] Экспорт только файла ответов из окна, результат идентичен `answerfile`
- [ ] Пароль сохраняется в профиль только в режиме «хранить пароль»
