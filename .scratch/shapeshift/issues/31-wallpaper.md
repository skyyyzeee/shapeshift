# 31: Обои рабочего стола

**What to build:** На шаге «Настройка» (карточка «Обои рабочего стола») пользователь выбирает картинку, положение (заполнение, по размеру, растяжение, по центру, замостить, расширение) и переключатель «Запретить менять обои» (по умолчанию включён). Картинка кладётся в образ и ставится всем пользователям; закреплённую нельзя сменить в «Параметрах».

## Заметки

- Запрет снимет только администратор компьютера (реестр, групповые политики) — это сказано в подсказке.
- Запись ISO повторяется (до 3 раз) при ошибке IMAPI «файл занят другим процессом»: антивирус проверяет только что записанные WIM.
- Окно проверено вживую (UI Automation + снимок): карточка заполняется из пресета, превью, сводка, шаг плана. Диалог выбора файла вживую не нажимался.
