# 23: Официальная загрузка как запасной источник

**What to build:** Если UUP недоступен, пользователь может скачать официальный ISO Microsoft прямо из программы — через механизм страницы загрузки Microsoft — и продолжить как со своим ISO. Если страница заблокирована (например, для российских IP), пользователь видит понятное объяснение. Сценарий спецификации: 9.
