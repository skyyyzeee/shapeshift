# 27: Уведомления об обновлениях и подпись каталога

**What to build:** Пользователь узнаёт о новой версии программы и обновлённом каталоге твиков: программа проверяет GitHub Releases и показывает уведомление, но ничего не устанавливает сама. Каталог обновляется без переустановки программы и принимается только с действительной подписью. Телеметрии нет. Сценарии спецификации: 75, 76.

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] Каталог подписан; движок отклоняет каталог с неверной подписью и продолжает работать с прежним
- [ ] Проверка новой версии программы и каталога через GitHub Releases; только уведомление
- [ ] Обновление каталога загружается по действию пользователя без переустановки программы
- [ ] Никаких данных, кроме запроса к GitHub Releases, программа не отправляет
- [ ] Проверку можно отключить в настройках
