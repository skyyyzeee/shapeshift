# 18: Список выпусков UUP

**What to build:** На шаге «Источник» пользователь выбирает «Скачать» и видит доступные выпуски Windows 10/11 x64 по версиям — данные приходят напрямую из Windows Update, без uupdump.net (ADR-0001), и работают с российских IP. По умолчанию видны каналы Retail и Release Preview; продвинутый режим добавляет Beta, Dev, Canary с предупреждением, что твики могут не работать. Для выбранного выпуска видны доступные языки и редакции. То же доступно командой CLI. Сценарии спецификации: 5–8.

## Заметки

- Протокол: SOAP к `https://fe3.delivery.mp.microsoft.com/ClientWebService/client.asmx` — `GetCookie`, затем `SyncUpdates` от имени анонимного x64-устройства (`DeviceAttributes`: версия, ветка, канал, совместимость). Выпуск — «листовое» обновление с `ProductReleaseInstalled Client.OS.*`; список файлов (имя, размер, SHA-1, SHA-256) — в его фрагменте `ExtendedProperties`. Формат запросов сверен с открытым UUP dump API (Apache-2.0); код свой.
- Каналы (`UupChannels`): последняя Windows 11 — двумя запросами (как с 23H2 и с 24H2), берётся самая новая сборка: служба отвечает на один и тот же запрос то 25H2, то 23H2. 24H2 — исходная 26100.1 («только эта версия»), обновление накатит задача 22. Windows 10 — как с 1909, только сборки до 19999. Release Preview — обычный режим; Beta, Dev, Canary — `--advanced`.
- Названия обычных выпусков строятся по сборке (служба называет 24H2 «Cumulative Update … Insider Preview»).
- Языки и редакции — по образам редакций `<edition>_<lang>.esd`: 38 языков, готовые редакции Core, Professional, CoreN, ProfessionalN, CoreCountrySpecific. Остальные — конвертацией (задача 21).
- Размер скачивания пока не показывается: образ редакции (~550 МБ) — лишь часть, остальное в пакетах; посчитать правильно — задача 19.
- Найденные выпуски кэшируются в `<рабочая папка>\cache\uup\<UpdateId>.json` — оттуда `uup release` и будущее скачивание.
- Тесты: записанные ответы службы (`Fixtures/WindowsUpdate`, списки файлов урезаны), живой тест — `SHAPESHIFT_TEST_LIVE=1`, категория `Live`. Сырые ответы для новых записей: `SHAPESHIFT_WU_DUMP=<папка>`.
- Окно: «Источник» → «Свой ISO» / «Скачать»; скачивание ещё недоступно — сообщение об этом на экране.
