# 18: Список выпусков UUP

**What to build:** На шаге «Источник» пользователь выбирает «Скачать» и видит доступные выпуски Windows 10/11 x64 по версиям — данные приходят напрямую из Windows Update, без uupdump.net (ADR-0001), и работают с российских IP. По умолчанию видны каналы Retail и Release Preview; продвинутый режим добавляет Beta, Dev, Canary с предупреждением, что твики могут не работать. Для выбранного выпуска видны доступные языки и редакции. То же доступно командой CLI. Сценарии спецификации: 5–8.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] Команда движка выдаёт список выпусков по каналам и для выпуска — языки и редакции
- [ ] Запросы идут напрямую в Windows Update; сторонние сайты не используются
- [ ] По умолчанию — Retail и Release Preview; Insider только в продвинутом режиме, с предупреждением
- [ ] Шаг «Источник → Скачать»: версия → выпуск → язык → редакции
- [ ] Сеть недоступна или Windows Update ответил ошибкой — понятное сообщение и предложение запасного источника
- [ ] Быстрые тесты на записанных ответах Windows Update (без сети); отдельный тест против живого сервиса
