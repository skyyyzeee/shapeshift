# Shapeshift

Shapeshift — программа для получения установочного образа Windows и подготовки его под пользователя: выбор редакций и языков, обход ограничений, автоматическая установка, твики. Результат — ISO, файл на флешке Ventoy или загрузочная флешка.

## Language

### Образ и его происхождение

**Образ** (`Image`):
Установочный носитель Windows в виде ISO — исходный или результирующий.
_Avoid_: дистрибутив, сборка, ISO-шник

**Источник** (`Source`):
Откуда берётся исходный образ: свой ISO, UUP или официальная страница загрузки Microsoft.
_Avoid_: провайдер, origin

**UUP** (`Uup`):
Способ получения Windows из файлов Windows Update, из которых собирается образ любого выпуска, редакции и языка.
_Avoid_: uupdump (это сторонний сайт, а не способ)

**Выпуск** (`Release`):
Конкретная версия Windows с номером сборки, например Windows 11 24H2 26100.2314.
_Avoid_: сборка, билд, версия

**Канал** (`Channel`):
Ветка, из которой приходит выпуск: Retail, Release Preview, Beta, Dev, Canary.
_Avoid_: ring, ветка обновлений

**Редакция** (`Edition`):
Вариант Windows внутри образа: Home, Pro, Education, Enterprise, Enterprise LTSC и т. д.
_Avoid_: версия, SKU, издание

**Архитектура** (`Architecture`):
Процессорная платформа образа: x64 или ARM64.
_Avoid_: разрядность, платформа

### Изменения

**Твик** (`Tweak`):
Одно именованное изменение образа или будущей системы, которое пользователь включает или выключает целиком.
_Avoid_: настройка, опция, патч, фикс

**Каталог** (`Catalog`):
Полный набор описаний всех твиков, разметки встроенных приложений и их метаданных, поставляемый отдельно от программы.
_Avoid_: база твиков, конфиг

**Действие** (`Action`):
Элементарная операция, из которых состоит твик: значение реестра, удаление приложения, команда.
_Avoid_: шаг, операция

**Этап** (`Stage`):
Момент, когда действие вступает в силу: в образе, во время установки или при первом входе пользователя.
_Avoid_: фаза, pass

**Файл ответов** (`AnswerFile`):
Файл автоматической установки Windows вместе с сопровождающими его скриптами, который кладётся в образ.
_Avoid_: unattend, автоответ, xml

**Офлайн-обслуживание** (`OfflineServicing`):
Изменение содержимого Windows внутри образа до установки: редакции, языковые пакеты, обновления, драйверы, приложения.
_Avoid_: интеграция, патчинг образа

**Встроенное приложение** (`ProvisionedApp`):
Приложение из магазина, которое образ устанавливает каждому новому пользователю.
_Avoid_: appx, bloatware, мусор

**Обход ограничений** (`Bypass`):
Твик, снимающий проверку требований установщика: TPM, Secure Boot, ОЗУ, процессор, обязательный аккаунт Microsoft.
_Avoid_: хак, кряк

**Ключ установки** (`SetupKey`):
Общедоступный ключ, который только выбирает редакцию при установке и ничего не активирует.
_Avoid_: ключ активации, лицензия

### Языки и регион

**Языковой пакет** (`LanguagePack`):
Пакет, добавляющий в Windows язык интерфейса; должен соответствовать выпуску.
_Avoid_: язык, локализация, MUI

**Компонент по требованию** (`FeatureOnDemand`):
Дополнительная часть языка или системы: рукописный ввод, OCR, речь, .NET 3.5.
_Avoid_: FoD в интерфейсе, фича

**Регион** (`Regional`):
Форматы даты и чисел, раскладки клавиатуры и часовой пояс будущей системы. Не является языком.
_Avoid_: язык, локаль, раскладка (как общее название)

### Выбор пользователя и результат

**Профиль** (`Profile`):
Сохранённый полный набор выборов пользователя, по которому можно повторить сборку.
_Avoid_: конфиг, настройки, проект

**Пресет** (`Preset`):
Профиль, поставляемый вместе с программой.
_Avoid_: шаблон, рецепт

**Сборка** (`Build`):
Один запуск получения и изменения образа с выдачей результата.
_Avoid_: генерация, job, задача

**Результат** (`Output`):
Во что превращается сборка: файл ISO, ISO на флешке Ventoy или отдельная загрузочная флешка.
_Avoid_: target, вывод

**Флешка Ventoy** (`VentoyDrive`):
Накопитель с Ventoy, на который результат кладётся как файл ISO.

### Работа программы

**Движок** (`Engine`):
Часть программы, которая выполняет сборку; работает с правами администратора и без интерфейса.
_Avoid_: бэкенд, сервис, воркер

**Интерфейс** (`App`):
Окно программы, где пользователь делает выборы и следит за сборкой.
_Avoid_: GUI, фронтенд, клиент

**Мастер** (`Wizard`):
Пошаговый путь выбора от источника до результата.

**Продвинутый режим** (`AdvancedMode`):
Переключатель, раскрывающий дополнительные выборы на тех же шагах мастера.
_Avoid_: экспертный режим, режим разработчика

**Хост** (`Host`):
Компьютер, на котором запущен Shapeshift.
_Avoid_: локальная машина

**Целевой компьютер** (`TargetMachine`):
Компьютер, на который будет установлена Windows из результата.
_Avoid_: клиент, устройство

**Рабочая папка** (`Workspace`):
Место на диске хоста, где движок держит промежуточные данные сборки.
_Avoid_: temp, scratch

**Кэш** (`Cache`):
Скачанные файлы, сохраняемые между сборками для повторного использования.
